# PHP Form Validation

A lightweight PHP 8.2 library designed to make form validation simple and secure. Validate user input effortlessly with an intuitive API and comprehensive validation rules.

![Preview](https://github.com/user-attachments/assets/13de5808-1749-4538-bd81-339c5c00a93c)

## ✨ Features
- Simple, intuitive validation API
- Multiple validation rules (required, email, numeric, etc.)
- Customizable error messages
- Lightweight and performant
- Easy integration with any PHP project
- PHP 8.2 compatible

## 🚀 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shubham-pawar/PHP-FORM-VALIDATION.git
   ```
   
## 🛠 Requirements
- PHP 8.2 or higher
- Web server (Apache/Nginx)
